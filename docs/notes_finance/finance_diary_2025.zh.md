#### 美国国债久期

2025年8月4日

美国国债是一个非常抗风险的产品，虽然不能说一点风险都没有，但矮子里拔将军，在众多具有风险的产品中，到底还是算那个最抗风险的。

久期（Duration）是衡量债券价格对利率变化有多敏感的指标。

> 经验之谈：利率每变动1%，债券价格大约变动“久期 x 1%”

题外话，最近打算买点国债，在选购美国国债的时候，我考虑了四个产品：

* 10年期美国国债
* 30年期美国国债
* IEF
* TLT

对比四个产品的数据：

| 工具       | 价格  | 收益率 | 对美联储利率变化的反映预估（4.35→3.50） |
| ---------- | ----- | ------ | ---------------------------------------- |
| TLT        | 95-96 | 4.86%  | +10%                                     |
| IEF        | 95-96 | 4.16%  | +5%                                      |
| 10年期国债 | 1000  | 4.38%  | +6.5%                                    |
| 30年期国债 | 1000  | 4.8%   | +15%                                     |

假设我的目标是持有5年，对赌美联储还能回到低利率时代，并且同时赚取稳定地分红收益的话：

* IEF：分红稳定，波动小，久期和5年较为匹配
* 10年期国债：每半年发放一次利息，中间变现稳定，价格波动适中

假设我的目标是通过稳定投资，20年后不再需要用劳动赚取收益，那么从2025年（T=0）开始，每过一年我在国债篮子中增投T万美元，假设平均年收益率是4%，那么：

| T  | 增投 | 持仓 | 年收益 |
| -- | ---- | ---- | ------ |
| 0  | 1    | 1    | 0.04   |
| 1  | 1    | 2    | 0.08   |
| 2  | 2    | 4    | 0.16   |
| 3  | 3    | 7    | 0.28   |
| .. | ..   | ..   | ..     |
| 20 | 20   | 210  | 8.4    |

到第20年，我每年的被动收益可以到8万美元。这样看来的话其实收益率并不算特别高，但是也不是特别低。考虑到目标是稳定的被动收益，加上200万美元的本金的话，其实并不算特别难实现。关键还是在于能否保持收入的持续增长，实现T年入T的规划，这点比年收益率4%更难一点。但我对我的收入预期还是比较乐观的，相信未来的我也能想到获得更高收入的方法。
