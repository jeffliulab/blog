#### 美联储、短期国债收益率、长期国债收益率

2025年8月27日

首先我们来学习一下美联储的常规工具：

1. 联邦基金利率：加息/降息
2. 公开市场操作（OMO）：买卖国债
3. 资产负债表政策：扩表QE/缩表QT
4. 前瞻指引（Forward Guidance）
5. 紧急贷款工具（Lending Facilities）：贴现窗口、PMCCF/SMCCF
6. 互换额度（Swap Lines）：美元互换协议
7. 特殊担保和信用工具：TALF，定向支持ABS/学生贷等

近端直接影响：当美联储宣布加息/降息、OMO的时候，短期国债收益率（特别是1年以内的）会被直接影响，因为联邦基金利率就是银行间超短期利率，几乎直接锚定短期国债收益率。

| 工具         | 方向     | 影响（短期国债）                   |
| ------------ | -------- | ---------------------------------- |
| 联邦基金利率 | 加息     | 短端利率上升，收益率曲线变平       |
| 联邦基金利率 | 降息     | 短端利率下降，收益率曲线变陡       |
| OMO          | 买入国债 | 提高需求，国债价格上升，收益率下降 |
| OMO          | 卖出国债 | 增加供给，国债价格下降，收益率下降 |

长端直接影响：当美联储使用QE/QT、前瞻指引时，会影响长期国债（10-30年）收益率。

| 工具       | 方向           | 影响（长期国债）                   |
| ---------- | -------------- | ---------------------------------- |
| 资产负债表 | QE             | 国债需求增加，价格上升，收益率下降 |
| 资产负债表 | QT             | 国债供给上升，价格下降，收益率上升 |
| 前瞻指引   | 长期维持低利率 | 未来预期降低，长端收益率下降       |
| 前瞻指引   | 长期维持高利率 | 未来预期增加，长端收益率上升       |

其他还有一些非常时期的特殊工具：

| 工具     | 方向           | 影响                                                                         |
| -------- | -------------- | ---------------------------------------------------------------------------- |
| 紧急贷款 | 贴现窗口       | 提供银行流动性，缓解短期资金压力，短端利率下降                               |
| 紧急贷款 | 公司债购买计划 | 稳定市场信用，降低企业融资成本，国债需求下降，长期利率可能但不绝对上升       |
| 互换额度 | 美元互换协议   | 保证全球美元流动性，压低短期美元融资成本，短端国债收益率下降                 |
| 特殊担保 | TALF/定向支持  | 稳定特定市场，缓解恐慌，投资者卖债避险需求减弱，长期国债利率可能但不绝对上升 |

因此，美联储利率的调整并不直接影响长端国债利率，而是需要结合整体的宏观情况来判断。换句话说，美联储降息后，虽然短期利率下降，但长端利率还需要结合更多的因素来看待。

```
20年期收益率 ≈ （未来短端利率的平均值） 
              + （未来通胀补偿） 
              + （期限溢价）
              + （供需压力/资金偏好）
```

举例来说，我们来看一下现在美国的数据：

* **20年期利率现状**

  * 名义利率 ≈  **4.86%** （8/25）
  * TIPS实际利率 ≈ **2.35%**
  * 隐含通胀补偿 ≈ **2.5%**
  * 与5y5y通胀预期（≈2.34%）一致
* **未来短端利率的平均值（政策路径）**

  * FOMC点阵图：2025年3.9%、2026年3.6%、长期约3%
  * 市场定价未来12个月降至3.2–3.4%
  * 短端均值温和下移，对长端有下压但非极度宽松
* **未来通胀补偿**

  * PCE同比2.6%，Cleveland Fed nowcast约2.7–2.9%
  * 长期市场预期锚在2.3–2.6%区间
  * 消费者调查近期抬升至~3%
  * 通胀补偿顽固居高，对长端不利
* **期限溢价**

  * ACM模型显示10年期溢价约0.5–0.8%
  * 利率波动指标MOVE约79，不低
  * QT仍在进行
  * 期限溢价为正且偏高，推升长端
* **供需/资金偏好**

  * QRA：10年$42bn、20年$13–16bn、30年$22–25bn，供给高位但稳定
  * 财政部增加买回频次，缓解流动性压力
  * 外资6月净流入$77.8bn，外资持债创纪录$9.13T
  * QT与赤字背景下供给端仍对长端有上行压力
* **公式统合**

  * 20年期利率 ≈ 短端均值（温和下移） + 通胀补偿（顽固2.5%） + 期限溢价（正且上行） + 供需压力（高位稳定）
  * 得到当前利率水平约4.8–4.9%
* **对TLT的含义**

  * 单纯降息不足以推高TLT
  * 若通胀补偿下不去 + 期限溢价维持高位 + 供给压力大 → 长端利率居高，TLT承压
  * 有利于TLT的组合：通胀预期回落、期限溢价收缩（QT放缓/风险溢价下降）、供给压力缓解
  * 不利于TLT的组合：通胀黏性、QT持续、赤字高企带来的供给与风险溢价上行

从而可以得出一个粗浅的结论，即：现在的 **TLT趋势偏弱** —— 尽管美联储在降息，但 **通胀补偿顽固、期限溢价偏高、财政供给压力大** ，长端利率维持高位，使得TLT缺乏持续上涨动力。

结合上述内容，我整理了一个粗浅版本的长期国债收益率Dashboard，加入到我的AI Financial Agent中，用作学习和投资指引。

#### 美国国债久期

2025年8月4日

美国国债是一个非常抗风险的产品，虽然不能说一点风险都没有，但矮子里拔将军，在众多具有风险的产品中，到底还是算那个最抗风险的。

久期（Duration）是衡量债券价格对利率变化有多敏感的指标。

> 经验之谈：利率每变动1%，债券价格大约变动“久期 x 1%”

题外话，最近打算买点国债，在选购美国国债的时候，我考虑了四个产品：

* 10年期美国国债
* 30年期美国国债
* IEF
* TLT

对比四个产品的数据：

| 工具       | 价格  | 收益率 | 对美联储利率变化的反映预估（4.35→3.50） |
| ---------- | ----- | ------ | ---------------------------------------- |
| TLT        | 95-96 | 4.86%  | +10%                                     |
| IEF        | 95-96 | 4.16%  | +5%                                      |
| 10年期国债 | 1000  | 4.38%  | +6.5%                                    |
| 30年期国债 | 1000  | 4.8%   | +15%                                     |

假设我的目标是持有5年，对赌美联储还能回到低利率时代，并且同时赚取稳定地分红收益的话：

* IEF：分红稳定，波动小，久期和5年较为匹配
* 10年期国债：每半年发放一次利息，中间变现稳定，价格波动适中

假设我的目标是通过稳定投资，20年后不再需要用劳动赚取收益，那么从2025年（T=0）开始，每过一年我在国债篮子中增投T万美元，假设平均年收益率是4%，那么：

| T  | 增投 | 持仓 | 年收益 |
| -- | ---- | ---- | ------ |
| 0  | 1    | 1    | 0.04   |
| 1  | 1    | 2    | 0.08   |
| 2  | 2    | 4    | 0.16   |
| 3  | 3    | 7    | 0.28   |
| .. | ..   | ..   | ..     |
| 20 | 20   | 210  | 8.4    |

到第20年，我每年的被动收益可以到8万美元。这样看来的话其实收益率并不算特别高，但是也不是特别低。考虑到目标是稳定的被动收益，加上200万美元的本金的话，其实并不算特别难实现。关键还是在于能否保持收入的持续增长，实现T年入T的规划，这点比年收益率4%更难一点。但我对我的收入预期还是比较乐观的，相信未来的我也能想到获得更高收入的方法。
